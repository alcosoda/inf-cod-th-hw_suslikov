# Внешние источники

Каждый заимствованный или сгенерированный фрагмент отмечен в коде комментариями
`=== BEGIN GENERATED ... #N ===` / `=== END GENERATED ... #N ===`, где N — номер записи ниже.

| # | Файл / фрагмент            | Источник                                                                                | Назначение                                                                                                                                                                                                                                                                                                                                                  |
| - | -------------------------------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | `ict/source.py` — весь файл | Claude Opus 5.5 (Anthropic), система генерации кода, через Claude Code | Загрузка JSON-описания источника, перевод вероятностей в `Fraction`, проверки корректности (нормировка, отрицательные вероятности, несуществующие модели/переключатели, пустой `source`, повторные ключи) |
| 2 | `run.py` — весь файл        | Claude Opus 5.5 (Anthropic), через Claude Code                                             | Интерфейс командной строки: `--variant`, `--s`, подкоманда `generate` (`--n`, `--seed`), вывод в UTF-8, обработка ошибок с ненулевым кодом возврата                                                                                                                           |
