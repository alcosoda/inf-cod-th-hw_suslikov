# ДЗ №1. Кодирование источников — вариант 19

Курс «Теория информации и кодирования», ЦУ. Условие: [`docs/task.pdf`](docs/task.pdf).
Python 3.11+, только стандартная библиотека. Все режимы запускаются из корня репозитория через `run.py`.

```bash
python run.py --variant                                            # вариант 19 и параметры
python run.py generate tests/sources/example2.json --n 40          # 1.1, режим 1
python run.py prob tests/sources/example2.json --n 1000 --seq 0 0  # 1.1, режим 2
python run.py entropy tests/sources/var_stationary.json            # 1.2, режим 1
python run.py code tests/sources/var_stationary.json --rate 2.5    # 1.2, режим 2
python run.py compress tests/files/ru.txt --stats                  # 1.3, сжатие
python run.py decompress tests/zmh/ru.txt.zmh --out out/ru.txt     # 1.3, восстановление
python run.py huffman 5 3 2 1 1 1                                  # сверка ручных задач (Хаффман, заголовок)
python tests/run_tests.py                                          # все тесты -> RESULTS.md
```

Коды возврата: 0 — успех, 2 — некорректный вход, 3 — чужой формат, 4 — файл обрезан, 5 — файл повреждён, 130 — Ctrl+C.

## Карта проекта

| путь | что это |
|---|---|
| `run.py` | CLI: разбор аргументов, печать, коды возврата |
| `ict/variant.py` | параметры варианта по s |
| `ict/source.py` | чтение JSON-описания источника, проверки, расширенный формат |
| `ict/task11.py` | 1.1: генерация реализации, точные вероятности блоков, частотная оценка |
| `ict/task12.py` | 1.2: проверка «стационарен и без памяти», энтропия, ℓ(n), лучшие блоки через типы |
| `ict/huffman.py` | 1.3: длины кодов Хаффмана, канонический код, декодирование |
| `ict/zmh.py` | 1.3: контейнер `.zmh` — заголовок, модель, биты, CRC-32, диагностики |
| `tests/sources/` | источники: примеры варианта, `bad/` (некорректные), `degenerate/` (вырожденные), `task12/` |
| `tests/files/` | файлы для сжатия (русский и английский текст, PNG, повтор байта, пустой, случайный) |
| `tests/zmh/` | входы для восстановления: целый `.zmh` и повреждённые |
| `tests/run_tests.py` | прогон всех тестов, генерация `RESULTS.md` |
| `tests/make_files.py` | воспроизводимое создание тестовых файлов 1.3 |
| `REPORT.md` | отчёт: проектные решения, таблицы, время, журнал неудач |
| `FORMAT_SPEC.md` | спецификация расширенного формата источника |
| `RESULTS.md` | вывод программы на собственных тестах |
| `DEFENSE.md` | команды и сценарии для защиты |
| `SOURCES.md` | декларация заимствованных и сгенерированных фрагментов |
| `docs/task.pdf` | условие задания |
